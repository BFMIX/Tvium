# Tvium Design Sources

This directory contains the approved visual direction for Tvium. Written rules are authoritative. Reference screens illustrate hierarchy and mood, but do not override accessibility, responsive layout, privacy, or platform behavior.

## Canonical guidance

- [Brand guidelines](BRAND_GUIDELINES.md) defines the locked header, visual direction, screen notes, and privacy rules.
- [Design system](../DESIGN_SYSTEM.md) defines implementation tokens, component states, and responsive behavior.
- The original branding-kit PDF remains local-only because it contains internal tool-specific working notes. It must not be committed or published.

## Runtime brand assets

Validated logos live in `apps/tvium_app/assets/branding/`:

- `logo-primary-color.png`: full-color symbol with light wordmark for dark UI.
- `logo-primary-dark.png`: full-color symbol with dark wordmark for light surfaces and repository presentation.
- `logo-monochrome-light.png` and `logo-monochrome-dark.png`: single-color lockups.
- `logo-symbol-color.png`, `logo-symbol-white.png`, and `logo-symbol-black.png`: symbol-only variants.
- `logo-stacked-color.png` and `logo-wordmark-dark.png`: alternate lockups.
- `app-icon-dark.png`, `app-icon-dark-safe-area.png`, and `app-icon-light.png`: application icon sources.
