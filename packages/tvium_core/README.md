# tvium_core

Shared, platform-independent domain rules for Tvium: media kinds, conservative title normalization and matching, and sensitive-data sanitization.

This package does not access a network, a database, or Flutter. Import `package:tvium_core/tvium_core.dart` from another workspace package when those rules are needed.

See [Product Definition](../../docs/PRODUCT.md) and [Security](../../docs/SECURITY.md) for the boundaries these rules support.
