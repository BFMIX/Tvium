# tvium_design_system

Shared Flutter colors, typography, spacing, and focusable controls for Tvium's TV-first interface.

Import `package:tvium_design_system/tvium_design_system.dart` for theme tokens and reusable focus behavior. Product screens and their state remain in `apps/tvium_app`.

See [Design System](../../docs/DESIGN_SYSTEM.md) and [Brand Guidelines](../../docs/design/BRAND_GUIDELINES.md).
